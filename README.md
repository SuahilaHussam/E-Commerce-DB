# E-Commerce SQL Database Project

## Project Overview

This project is a relational database system designed for an E-Commerce platform. It manages customers, products, categories, orders, order details, payments, and other related business data.

## Technologies Used

* SQL Server
* T-SQL
* SQL Server Management Studio (SSMS)

## Database Features

* Relational database design
* Primary Keys and Foreign Keys
* Constraints
* Indexes
* Views
* Stored Procedures
* Functions
* Triggers
* Complex SQL Queries
* Data Aggregation
* Joins

## Main Entities

* Customers
* Products
* Categories
* Orders
* Order Details
* Payments
* Reviews

## SQL Concepts Implemented

* SELECT, INSERT, UPDATE, DELETE
* INNER JOIN and LEFT JOIN
* GROUP BY and HAVING
* Subqueries
* Aggregate Functions
* CTEs
* Views
* Stored Procedures
* User-Defined Functions
* Triggers
* Indexing

 Project Objectives

The main objectives of this project are:

* Designing a well-structured relational database.
* Managing E-Commerce business data efficiently.
* Implementing database constraints and relationships.
* Improving query performance using indexes.
* Using SQL Server advanced database features.
* Writing queries for data analysis and business requirements.
